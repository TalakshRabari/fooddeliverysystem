# 🍽️ Food Delivery System

An online food ordering platform designed for a single restaurant, enabling customers to browse the menu, place orders, and track their purchases through a seamless web interface. The system provides restaurant owners with tools to manage food items, orders, and customer interactions efficiently.

## 🚀 Features

### Customer Features

* User registration and authentication
* Browse restaurant menu and food categories
* Search and filter food items
* Add items to cart
* Place online food orders
* Order summary and checkout
* Responsive user interface

### Restaurant Admin Features

* Secure admin authentication
* Add, update, and delete food items
* Manage menu categories
* View and manage customer orders
* Update order status
* Monitor restaurant inventory and offerings

### Payment Simulation

* Integrated payment gateway simulation for checkout workflow
* Order confirmation after successful payment

## 🔧 Installation

1. Clone the repository

```bash
git clone https://github.com/TalakshRabari/fooddeliverysystem.git
```

2. Navigate to the project directory

```bash
cd fooddeliverysystem
```

3. Install dependencies

```bash
npm install
```

4. Configure Firebase credentials

Create a Firebase configuration file and add your project credentials.

5. Start the development server

```bash
npm start
```
